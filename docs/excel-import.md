# Excelで営業マスタを更新する

Googleの外部共有が許可されない場合、スプシをExcelとしてダウンロードして手動更新できます。共有制限は変更しません。取り込んだ表の保存先はWorknestのクラウド環境です。

1. スプシで「ファイル → ダウンロード → Microsoft Excel（.xlsx）」を選択します。
2. Worknestの「営業・数字管理 → データ連携」を開き、上部の対象月を確認します。
3. 「Excel / CSV / TSV を選択」からファイルを指定します。
4. 「対象シート」と「見出し行」を確認します。最初の50行にアカウントID・アカウント名があれば見出し行を自動選択します。
5. 「取込内容を確認」で件数・ID・金額・警告・列対応を確認します。この時点で選択した表をサーバーへ送信しますが、業務データは保存しません。
   「ヨミの対応を確認」では、今月ヨミ・アグレッシブ数字・ヨミ根拠の列を直接選択できます。週次ヨミへ移す場合は「初回移行」にチェックしてください。
6. 管理者が「この内容で取り込む」で確定します。同じアカウントIDは更新され、ファイル名・シート名・見出し行・実行者・時刻が履歴に残ります。

Excelブックはブラウザー内で解析します。他のシートや元ファイル全体をサーバーへ保存しません。選択した表の補足列は原文として保存します。1ファイル10MB、1回5,000件・200列までです。大きい表は行・列を分けてください。旧形式.xls、暗号化ファイルは.xlsxに保存し直す必要があります。

数式は保存済みの計算結果を利用し、Worknest側では再計算しません。未計算・計算エラーは空欄になるため、元のスプシで計算完了後にダウンロードしてください。アカウントIDの先頭ゼロは元ファイルで文字列にします。金額は円です。

前月実績・Gトレの0円と空欄はそのまま取り込めます。配信停止・未反映の場合も追加入力は不要です。Excel内部の指数表記（例：1.2E7）は通常の金額（12,000,000円）へ変換します。読み取りエラーを0円へ置き換える処理は行いません。

更新時は再ダウンロードして同じ手順で取り込みます。Excelファイルからの自動・日次同期はありません。週次の手入力ヨミ、商談、議事録、タスクはマスタ更新で上書きしません。初回だけ既存ヨミを移行する場合は「未登録の当週ヨミだけスプシから補完する」を使います。
