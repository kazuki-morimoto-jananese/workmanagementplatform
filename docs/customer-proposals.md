# 顧客向け提案資料・PowerPoint出力

KW分析、LINEバイト・配信面分析で保存した結果から、顧客に提出する資料を作成できます。追加のGoogle権限やAI APIキーは不要です。社内の営業会議用Google Slidesとは別の機能です。

## 操作手順

1. **営業・数字管理 → 商談準備・分析** で対象アカウントを検索します。
2. Excel／CSVで期間A・Bを分析して **分析・提案を共有保存**。すでに保存している場合は「保存した分析」から開きます。
3. **顧客向け提案資料を作成** を押します。
4. 提出先・提出元・日付、提案サマリー、CV定義、比較条件、次のアクションを入力します。掲載する注目明細は最大8件、改善提案は最大6件です。提案文も編集できます。
5. プレビューを確認し **提案資料を共有保存**。ワークスペース内のメンバーが保存履歴から開けます。
6. 「提出先・期間・数値の定義・提案文・掲載情報を確認した」を選択し、**PowerPointをダウンロード**。**提案資料をPDF保存** では印刷画面の保存先をPDFに指定します。

PowerPointの数値・文章・棒グラフは編集可能な図形です。フォント置換などの表示差があるため、送付前に利用するPowerPointで確認してください。PDFの背景色を残す場合はブラウザーの「背景のグラフィック」を有効にします。Worknestから顧客へのメール送信は行いません。

## 資料に含まれるもの

- 表紙、提案サマリー、比較期間・CV定義・比較条件。
- 全対象の消化額／表示回数／クリック／CV／CPC／CVR／CPAの比較、差分、消化額・CV・CPAの棒グラフ。
- 選択したKWまたは配信面の実績、選択した改善提案と元分析の根拠、次のアクション。
- 出典の期間・集計元行数・計算版、分析範囲・欠損値・因果関係などの留意事項。

数値は保存済み分析からサーバーで再構成します。提案資料で元の数値を書き換える入力欄はありません。未知・未提供・分母0の値は「—」、数値0は「0」とし、CVRの差分はポイントで表します。日数の異なる期間を自動的に同条件とみなすことはありません。提案は元分析のルールと担当者の編集に基づき、AIの新たな推論や効果の保証を加えません。

競合広告主比較は任意掲載、広告主名は初期状態で匿名です。元ファイル名も任意掲載です。アカウントID、ファイルのハッシュ、元のタブ名、キャンペーンID、社内の議事録や非公開タスクは自動では資料に載せません。担当者が入力する文章の内容は提出前に確認してください。

## 保存と改訂

保存時点の文面・掲載設定・スライド内容・参照分析ID／ハッシュを保持します。編集後の **新しい版として保存** は元の版を上書きせず、改訂元と作成者・作成日時を残します。保存履歴から開いた版は保存時の内容で再出力できます。元分析も変更しません。

同じ保存リクエストの再送では二重登録せず、アカウントの異なる分析や改訂元を指定すると拒否します。監査履歴と管理者のワークスペース全体エクスポートにも含まれます。画面だけの未保存編集はブラウザーの再読み込み・対象アカウントの切替で失われるため、共有保存してください。

## Cloudflare無料構成での範囲

PPTXは必要時だけライブラリを読み込み、利用者のブラウザーで生成します。PDFもブラウザー印刷を使用します。PPTX／PDF本体はサーバーに保存せず、新規の定期実行・外部AI呼出し・有料ストレージは追加しません。

保存内容は1版120KBまで、1ワークスペースで500版かつ20MBまで（監査履歴・DB索引は別）。1資料60ページまでです。履歴一覧は対象アカウント・分析の索引を使い、スライド本体は個別に取得します。上限時は新規保存を停止しますが、保存済み版の再取得・ダウンロードは可能です。自動削除はしません。

これらは本機能の上限であり、Cloudflare全体の無料枠残量を保証するものではありません。既存機能と合算した使用量は管理画面でも確認してください。

## 実装範囲

Google Slidesへの直接保存、Databricksからの自動分析取得、AIによる新規提案生成、メール送信は今回の対象外です。入力元と資料生成は保存済み分析で分離しており、将来APIから同じ分析形式を作成すれば、この資料作成フローを再利用できます。

共有モデル: `shared/customer-proposal.mjs`。保存API: `server/customer-proposals.mjs`。ブラウザー出力: `src/proposal-pptx.ts`。
