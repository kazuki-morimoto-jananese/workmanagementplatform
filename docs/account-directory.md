# アカウントマスタ

営業サマリーの固定KGI表の下、または「アカウントマスタ」タブから確認できます。初期表示はログインしたメンバーの担当アカウントのみです。担当者選択で別の担当者や全件へ切り替えられます。これは表示の絞り込みであり、同一ワークスペース内のアクセス権限を分割する機能ではありません。

## 表示

14項目を12pxの表で表示し、ID・アカウント名を固定します。スマホではアカウント名を固定し、横スクロールで残りの項目を確認できます。50件ずつのページ表示、ID・アカウント名・代理店・業種等の検索に対応します。空欄は「—」、明示的なゼロは「0」。金額は円単位です。デモ画面には実マスタを表示しません。

## 接続・更新

管理者が「マスタ連携を設定」からGoogle本人認証で接続します。既存のヨミ同期・固定KGIサマリー接続とは独立しています。

- 基本情報の範囲例: `'ヨミ表（売上）'!A4:M`
- 9月の数値範囲例: `'ヨミ表（売上）'!AW4:AZ`

末尾の行番号を指定しないため、下に追加された新規行も同期されます。上限は見出しを含む20,001行、Googleレスポンスは既存の4MiB制限です。上限や取得エラー時は前回成功分を保持し、部分的な上書きをしません。

設定保存→プレビュー→同期の順で利用します。日次同期は日本時間で設定します。対象月と数値列の直前行の月見出しを照合します。**対象月・対象列は翌月に管理者が切り替えます**。年がない元シートの「9月」表記だけから年度は推測しません。

## 担当者と既存データ

Worknestのメンバー名とマスタ担当者名を空白・全角半角を正規化して照合します。同姓同名が複数ある場合は自動紐付けしません。略称などの場合は設定内の「担当者名とWorknestメンバーの紐付け」で指定します。設定変更後の同期で反映します。

アカウントIDは文字列のまま保持します。新規IDのみ共通アカウントへ追加し、タスク・商談などで選べるようにします。既存アカウントのプロジェクト・担当者設定や週次ヨミ・個人目標・議事録は上書きしません。マスタ画面の氏名・当月担当・数値は月別の取り込みレコードを使用します。

月別レコード、変更監査、同期履歴を永続DBへ保存します。同じ値の再同期では変更履歴を増やしません。元シートから消えたIDは当月一覧から除外しますが、アカウント・過去履歴・タスクは削除しません。予算やGトレを既存の手入力ヨミに自動加算しません。
