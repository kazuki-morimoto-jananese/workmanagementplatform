# メンバーの初回Google連携

Google OAuthが設定済みの環境では、ログイン・初回パスワード変更の後にGoogle連携案内を表示する。既存メンバーも未連携または権限不足なら次回読み込み時に対象となる。

「Googleに接続して必要な権限を許可」から既存の本人認証（PKCE・ユーザーとメールの照合・暗号化トークン保存）へ進む。要求権限はDocs読み取り、Driveメタデータ読み取り、Sheets読み取り、Calendar予定読み取り、アプリが扱うDriveファイルの作成・更新。Drive全体の書き込み権限は要求しない。

必要な権限をすべて付与済みなら案内は表示しない。未付与なら再表示する。「後で設定」は利用者ごとにサーバーに保存し、以後はデータ連携画面から接続する。未連携でも通常のタスク管理は利用可能。Google側の設定がない環境には案内しない。

他のメンバーのGoogle権限やファイルアクセスを引き継がない。Googleでの同意は本人が行う。WorkspaceのAPI制限、OAuthアプリの公開対象・テストユーザー制限はこの画面では変更しない。新規メンバーの実アカウントで認証が許可されるかは、会社側の設定にも依存する。

検索時点ではDrive内の情報をチームへ共有しない。選択して取り込んだ議事録はワークスペース全員に共有されることを案内する。
