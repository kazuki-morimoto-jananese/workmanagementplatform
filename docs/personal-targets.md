# 個人目標・Excelヨミ

営業サマリーの「個人目標と予実」で、管理者が「個人目標を編集」を選びます。対象月を確認し、チーム名と担当者ごとの月間目標を入力して保存してください。アカウントがない担当者も追加できます。空欄は未設定、0は目標0円です。

- 当月目標は個人目標の合計です。Excelのアカウント別「今月目標」は参考値として保存されますが、個人目標には合算しません。
- 今週Gトレ合計は、対象月のマスタにある各担当アカウントのGトレ合計です。取得したマスタの最新値であり、選択した過去週の時点の値ではありません。
- ヨミは選択週以前の最新の週次入力を優先し、週次入力がないアカウントはExcel「今月ヨミ」を表示します。アグレッシブ数字・確度・ヨミ根拠も同じ優先順位です。二重加算はしません。
- Excel由来の値は「Excel取込」と表示します。週次確認済み件数には数えません。Excelの再取り込みで更新されますが、手入力で保存した週次記録は上書きしません。
- 差分はヨミ−個人目標、達成率はGトレ÷個人目標です。0円目標の達成率は「—」、未入力を含む合計は既知の数値の小計です。
- 個人目標の表は、選択月・実データ／デモ内の担当者全体を集計します。上部検索によるアカウント絞り込みはこの表に適用しません。
- 担当者名は全角・半角と空白を正規化して照合します。同姓同名を区別する場合は、部署名などを含む統一した担当者名を使用してください。

週次ヨミではアグレッシブ数字の右側に確度を表示します。「確定・A・B・C・ネタ・停止」から選択でき、取り込んだ独自の値も保持します。ランクからパーセントへの自動換算はしません。確度を変更すると、表示中のヨミ・アグレッシブを含む当週の記録が保存されます。

個人目標は対象月・実データ／デモ別に保存し、変更履歴と全データバックアップに含まれます。同じ目標を同時に編集した場合、後から古い内容で上書きする操作は拒否されます。目標の設定・変更は管理者、閲覧は社内メンバーが行えます。
