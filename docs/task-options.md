# 繰り返しと公開範囲

タスクの作成・編集画面で設定します。

- **社内公開**：ログインした社内メンバー全員が閲覧できます。インターネット全体への公開ではありません。
- **非公開**：作成者・担当者・管理者が閲覧できます。管理者は監査・全データバックアップでも確認できます。作成者と管理者だけが公開範囲を変更でき、非公開タスクの担当者を追加・変更できます。
- 非公開タスクは、権限がないメンバーの一覧・通知・活動・監査履歴・議事録のタスクリンクから隠れます。IDを指定した編集・コメント・削除・承認・カレンダー出力も拒否します。
- 非公開タスクの承認は、担当者か管理者に依頼します。プロジェクトの自動ルールでは非公開タスクに新しい担当者を追加しません。
- 公開範囲はタスク単位です。元の議事録・営業アカウント・プロジェクトまで非公開に変わるわけではありません。

**繰り返し**は日次・週次・月次と1〜12の間隔を指定します。期日の設定が必要です。タスクを完了すると、元の期日を基準に次回タスクが1件作成されます。未完了のまま毎週・毎月自動追加する方式ではありません。

月末は短い月の末日に調整し、次の月には元の日付へ戻します。例：1月31日→2月28日→3月31日。開始日から期日までの日数も維持します。

次回タスクには説明・担当者・公開範囲などを引き継ぎ、完了状態・コメント・承認・依存関係はリセットします。過去の完了タスクは残ります。完了を取り消して再度完了しても、次回タスクを重複作成しません。すでに作られた次回タスクを止める場合は、その次回タスクの「繰り返し」を「繰り返さない」に変更してください。
