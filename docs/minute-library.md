# 議事録の収集・一覧とアカウント検索

「営業・数字管理 → 議事録」で利用します。

## 担当者とアカウント

初期表示は「自分の担当アカウント」です。「議事録の担当者」で他のメンバー、マスタ上の担当者名、全担当者に切り替えられます。閲覧権限を変更する機能ではなく、一覧の絞り込みです。

現在の営業アカウントの担当者IDを優先します。IDが未紐づけの場合は、空白・全半角を正規化した担当者名が一意のメンバーに一致するときだけ本人の担当として扱います。同姓同名や担当未入力は推測せず「すべての担当者」で確認してください。過去の議事録も現在の担当アカウントに基づいて表示します。

議事録はアカウント名順にグループ化し、各アカウントの中を商談日の新しい順に並べます。カードにサマリーと決定事項を表示します。未要約の原文をサマリーとして表示することはありません。検索ではタイトル・原文・要約・アカウント名を参照します。

## 一括収集

1. 「顧客のフォルダーから議事録を収集」を開きます。
2. 自分の担当すべて／担当者指定／複数アカウント選択／個別指定を選びます。
3. Google接続済みの本人が読める検索元フォルダーを指定し「保存して候補を検索」を押します。フォルダー設定は本人ごとに保存されます。
4. 候補の取り込み先と会議日を確認します。文書タイトルに明示された日付は候補として補完します。日付不明は手入力、複数アカウント一致は取り込み先を選択してください。
5. 「アカウント・日付がある未登録分をすべて選択」または各チェックで選択し、一括取り込みを実行します。

同じフォルダーを担当アカウントごとに繰り返し走査せず、1回の探索で照合します。1回500アカウントまで。探索の上限・Google接続要件は [Drive収集](drive-collection.md) と同じです。

候補情報は本人のみ、取り込んだ議事録はワークスペース全員に共有します。新規取り込みは順次処理し、登録済みの文書・アカウント組み合わせは除外します。エラー時は後続を止め、成功分を保持して各文書のエラーと未処理件数を表示します。重複登録エラーの場合は再検索して登録状態を更新してください。中断は実行中の1件が終わってから停止します。

一括取り込み時にGemini要約・数値抽出は自動実行しません。取り込み後、必要な議事録から要約を作成できます。無料枠のGoogle・Gemini・Cloudflareの利用上限は引き続き適用されます。

## タスクのアカウント検索

タスク編集の「対象の営業アカウント」で名前またはIDを入力し、候補をクリック、または矢印キーとEnterで確定します。候補は最大50件なので、文字を追加して絞り込めます。入力しただけでは紐づけは変わりません。「紐づけを解除」で未設定に戻せます。議事録由来のタスクは従来どおり取り込み元アカウントに固定されます。

## 検証

担当者ID優先・一意の名前照合・同姓同名の除外、複数アカウントの1回探索、曖昧な文書の候補表示、所有者フィルター、グループ表示、日付確認、一括取り込みと重複除外、スマートフォン表示を検証しています。外部Google APIはテスト応答を使い、業務文書の一括取り込みを自動テストでは行いません。
