# 営業サマリーのグループView

営業サマリーの「組織別営業サマリー」は、サマリー専用スプレッドシートの固定KGI表です。下部のグループViewを切り替えても変わりません。従来の個人目標・ヨミ・タスクは同名のViewから利用できます。

初期グループは総合企画EPG、総合企画G、CSG、RDG、RAG。「総合企画」は「総合企画G」と同一視します。所属は取得元のグループ列を使用し、Worknestのメンバー・組織マスタを自動変更しません。CS（メディア）等の集計担当行も元の名称で保持します。

初期の指標構成:

- 全グループ: KGI（売上）
- EPG・総合企画G・CSG: 入札CPC
- RDG・RAG: 当月稼働開始社数
- RAG: 商談実施数

管理者は「ダッシュボードを設定」で、指標名、表示列、列位置、表示対象グループ、指標の順序を変更できます。独自KPIの追加・削除にも対応します。設定は月別・社内共有で、他の管理者との競合を検知します。

## 接続

既存の営業マスタ／ヨミ同期から独立した設定です。Google Sheetsの本人認証を済ませた管理者が設定・同期します。接続者を変更しない限り、他の管理者による設定保存でも接続者は変わりません。

共通のスプレッドシートURL/IDを入力し、各指標の取得範囲を設定します。固定表だけ別ファイルにする場合は指標個別のIDを指定します。見出し行を含めて指定してください。

行名と対象月の数値が離れている場合は「行名の別範囲」を使用します。固定表は組織名1列、それ以外は担当・グループの2列。数値側と同じシート・開始行・終了行を指定します。列位置は行名と数値を連結した左端を1とします。他の月の数値は取得しません。

1. 設定を保存
2. 保存済み設定をプレビューし、対象月・行数・項目を確認
3. 今すぐ同期
4. 必要に応じて日次同期を有効化（日本時間）

取得月は自動で切り替えません。翌月は新しい月の設定を保存し、対象列を指定します。過去月の自動更新が不要になったら、その月の日次同期を無効化してください。

## 数値と履歴

数値はスプシの表示値です。達成率・合計・社単・前月比は再計算しません。空欄は「—」、明示的な0は0。入札CPCの大小が望ましいかも独自に判定しません。実績基準日は元シートによります。取得日時を「昨日の実績確定日時」とはみなしません。

すべての設定済み指標の取得に成功した場合だけ、月別スナップショットを一括保存します。失敗時は前回成功分を保持し、エラーを表示します。履歴は永続DBに蓄積し、画面では直近30回の取得日時を表示します。設定とスナップショットは監査・バックアップ対象です。手入力ヨミ・個人目標・商談・議事録は更新しません。

Viewは閲覧範囲を制限する権限機能ではありません。同一ワークスペースのメンバーがグループ別ダッシュボードを閲覧できます。デモ表示には実データのダッシュボードを混在させません。
