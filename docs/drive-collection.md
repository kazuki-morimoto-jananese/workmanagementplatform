# 顧客フォルダーから議事録を収集

営業・数字管理 → 議事録 →「顧客のフォルダーから議事録を収集」を開く。

1. 検索元のGoogle DriveフォルダーURLを1行に1件入力（最大10件）。設定は利用者ごとにサーバーへ保存される。
2. アカウントを選択。必要なら今回の検索に使う会社名・サービス名の別名を追加する。
3. 「保存して候補を検索」。マイドライブと共有ドライブの実フォルダー配下を再帰検索する。本人のGoogle閲覧権限が必要。
4. 候補のパス、一致名称、元の文書を確認して会議日を指定し、1件ずつ取り込む。
5. 取り込んだ内容はワークスペース全員が閲覧可能。Google側の共有設定は変更しない。原文取り込み後に既存の要約・数値抽出・更新検知を利用できる。

検索中は文書本文を取得せず、名前とパスのみを照合する。NFKC・空白・記号・株式会社等の表記差を吸収するが、法人と商品アカウントの同一性は自動確定しない。本文にしかない名称、PDF、ショートカットは対象外。ショートカットの実フォルダーを検索元に追加する。

1回の通信は1フォルダーの100件分。ページ送りし、20階層・3,000フォルダー・5,000ページ・2,000候補で打ち切りと注意を表示する。エラー範囲も表示し、部分検索を完全な結果とは扱わない。検索セッションは1時間・利用者単位で保持し、サーバー再起動時は再検索が必要。候補や検索履歴は永続保存しない。検索中断後は再検索する。

GoogleファイルIDで候補を重複排除。同じアカウントへ登録済みの原文は選択不可で、既存議事録から更新する。別アカウントに同じ文書を関連付ける場合は、アカウントを切り替えて取り込む。会議日は更新日時から推測しない。検索のみでは要約・ヨミ更新・タスク作成を行わない。

実装根拠: [Drive検索](https://developers.google.com/workspace/drive/api/guides/search-files)、[共有ドライブ対応](https://developers.google.com/workspace/drive/api/guides/enable-shareddrives)。
