# Worknest 要件定義 v1

> v2で営業管理・Google Sheets読取・Gemini議事録要約を追加しました。追加要件と定義は [営業管理ガイド](sales-guide.md) を参照してください。以下は初期版の範囲です。

## 目的・利用範囲
社内メンバーがチームのプロジェクト・タスク・依頼を一元管理する小規模向けWebアプリ。Asanaを参考にした独立した製品。日本語UI。全メンバーが同じワークスペースの全プロジェクトを閲覧・編集できる。プロジェクト単位の秘密情報管理は対象外。

## 認証・権限
- 初回だけ管理者を登録。以降は管理者のみメンバーを作成できる。公開の会員登録なし。
- メールアドレスと12文字以上のパスワードでログイン。管理者が作成したアカウントは初回にパスワード変更必須。
- 管理者: メンバー作成・無効化、通常の全操作。一般メンバー: プロジェクト・タスク操作。
- パスワードをscryptでハッシュ化。サーバー側セッション、HttpOnly Cookie、有効期限、ログイン試行制限、同一オリジン検証。無効化でセッション失効。
- 本番の初回セットアップには環境変数のトークンが必須。メールドメイン制限は設定可能。

## 優先実装
1. ホームの進捗・期限・担当タスク、プロジェクト作成と編集。
2. タスクの作成・編集・削除、詳細、担当者、開始日・期限、優先度、タグ、コメント。
3. 同一タスクをリスト・ドラッグ可能なカンバン・タイムラインで表示。依存関係の設定と可視化。
4. 検索、担当者・優先度・期限フィルター、複数プロジェクト所属。
5. 承認担当者への申請・承認／差し戻し、アプリ内の通知。
6. ログイン必須の社内依頼フォームからタスクを生成。
7. プロジェクト別カスタムフィールド（文字列・数値・選択肢）。
8. ステータス変更時の担当者・期日自動設定ルール。
9. Google Drive資料URLをタスクに紐付け。Google Calendar予定作成画面を開き、ユーザーが保存。ICSダウンロード。
10. SQLite永続保存。自動ポーリングで他メンバーの更新を取得。

## 今回の対象外
外部公開フォーム、Google OAuth/SSO、Googleとの双方向同期、Slack送信、AIエージェント、メール配信、添付ファイルのアップロード、プロジェクト単位のアクセス権、大規模な同時アクセス。Google連携はリンク・ファイル連携で、OAuth資格情報は不要。

## 技術・運用
Node.js 24以上、React + TypeScript + Vite、Node標準SQLite、単一サーバー。ローカルで即起動可能。社内共有・クラウド運用はHTTPSリバースプロキシと永続ボリュームを使う。クラウド契約・ドメイン・社内アカウント情報が未提供のため外部公開は実施しない。SQLiteファイルはアプリ停止中にバックアップする。

## 受入基準
未認証APIアクセスが拒否される。管理者だけがユーザーを作成できる。ログイン後にタスクを作成し各ビューで同じ更新を確認できる。再起動後もデータが保持される。コメント・承認・自動化・フォームが保存される。型チェック・本番ビルド・APIの認証と主要業務フローのテストが成功する。
